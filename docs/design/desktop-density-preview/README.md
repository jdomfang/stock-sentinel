# Desktop density preview

High-fidelity review mockup for the desktop-only workspace contraction.

- `market-scan-compact-command-panel.png` combines the page introduction and
  task controls into one command panel, retains the signed-in navigation tabs
  and 44px controls, and replaces the bordered empty-state card with a quiet
  inline status.
- `deep-analyze-compact-command-panel.png` applies the identical command-panel
  geometry to ticker analysis, with Deep Analyze active and matching credit
  and empty-state treatment.
- Tablet and mobile layouts are intentionally unchanged.
- This is a review artifact, not a production screenshot.

Generated with the built-in image generation tool using the current Market
Scan and Deep Analyze screenshots as visual references. The prompt required the
existing navy, slate, white, muted blue-gray and cyan visual system; exact
navigation and task copy; no FAQ search; no extra controls; and no orange or
coral accents.
