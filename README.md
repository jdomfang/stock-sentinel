# Stock Sentinel

**X-Powered Stock Sentiment Analysis**

Stock Sentinel is an AI-powered tool designed for short-term stock trading insights using real-time X (Twitter) sentiment analysis.

## Features

- **Discovery Page**: Find trending stocks based on X sentiment
- **Deep Analysis Page**: Detailed sentiment and financial analysis for specific stocks

## Technology Stack

- Streamlit for interactive multi-page web interface
- Transformers & PyTorch for AI-powered sentiment analysis
- Polygon API for financial data
- Real-time X data integration

## Getting Started

1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
