# Railway service; utils.sentiment calls it over HTTP. They were ~2GB of the
# install (torch alone ~1.6GB plus 12 nvidia-* CUDA packages that are pure
# waste on a CPU box) and ~886MB resident once loaded, against a ~1GB tier --
# which is what OOM-killed a scan mid-run on 2026-08-01.

# if inference is unreachable, analyze_sentiment_batch raises and the caller's
# try/finally refunds the credit. A failure the user is told about beats a
# silent fallback nobody notices -- the service ran 40x degraded for hours
# precisely because the fallback hid it.
